# Stream Deck, home page layout

**Read the deck top to bottom, press it bottom to top.** The top row is for the eye (what's next), the bottom row is for the hand (what you press all day), and the folders sit in between.

Assumes the deck sits just in front of the keyboard, with the bottom row nearest the hand. Row 1 is the far row.

## 15-key home page (5 x 3)

| | Col 1 | Col 2 | Col 3 | Col 4 | Col 5 |
|---|---|---|---|---|---|
| **Row 1, glance** | Next meeting (live) | Today (Day Board) | blank | blank | Sabbath / Rest |
| **Row 2, folders** | Recruiting | Family (KDTW) | Tools | blank | blank |
| **Row 3, press** | Join | Talk to Radar | Log a note | Focus block | Call |

## Why each key sits where it does

| Key | Reason |
|---|---|
| Next meeting | Top left is where the eye lands first. It stays in Join's column, so "what" sits above "go". |
| Join | Bottom left, the easiest key to hit without looking. It turns cream 15 minutes before a call, like the Day Board. |
| Talk to Radar, Log a note | Used most between calls, so they sit next to Join in the home row. |
| Focus block | Used a few times a day. Near the hand, away from Join. |
| Call | Far right edge with a blank above it. It opens a pad and never dials in one press, so a slip costs nothing. |
| Today | Next to the live key: both are "look" keys. Takes the brass dot when the board has something waiting. |
| Folders | The middle row is a shelf. Opening a folder is always harmless, so it is fine near Join. |
| Sabbath / Rest | Top right corner, used once a week, fenced by blanks. Press and hold to begin, so it never fires by accident. |
| Blanks | Breathing room and space for whatever Q's research earns a place. Fill one only when a key is used daily. |

## Bigger and smaller decks

| Model | How the layout grows |
|---|---|
| XL, 32 keys (8 x 4) | Keep this 15-key block bottom left, unchanged. The new top row becomes a live strip (next three meetings, unread counts). The three new right-hand columns lift the most-used folder keys onto the home page. |
| Stream Deck +, 8 keys and 4 dials | Keep the press row (Join, Radar, Note, Focus) on the bottom four keys, and the glance keys plus two folders on top. The touch strip shows the next meeting. Dials: volume, focus length, scroll the day's meetings, brightness. |
| Sabbath | Work keys go dim and do nothing. Family stays awake. The live key counts down to Saturday sundown. |

## Three questions for Kev

1. **Which deck do you have, or want?** 15-key, XL or Stream Deck +. The XL and the + change the home page more than anything else.
2. **Dark keys or cream keys?** Dark (recommended) is calm on the desk and makes "turns cream" a strong signal. Cream keys match the Eden paper but glow all day.
3. **Words under icons, or icons only?** Words (recommended) for the first month while the layout is learned. Icons only is quieter once the deck is in your hands every day.
